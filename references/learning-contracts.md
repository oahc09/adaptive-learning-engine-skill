# 学习路径、交互方式与输出契约

## 路径与交互方式

只读取当前主路径和交互方式。用户指定的产出与默认结构冲突时，优先满足用户明确要求，并说明必要调整。

### A · 渐进式卡片库

适合长期、系统掌握大学科。

1. 建立从基础到目标层级的全局地图，但只展开达到目标深度所需的有效路径。
2. 根据当前水平折叠已具备证据的节点；不因固定 L0–L4 形式重复教授已掌握内容。
3. 每张卡只讲一个知识点。约 300 个中文字指核心正文，不包含标题、依赖、衍生和自测题；用户指定长度时以用户要求为准。深度为进阶及以上时，核心解释后追加边界条件与一个反例，长度可适当放宽。
4. 卡片包含：标题、核心解释、一个例子、本卡依赖、下一张衍生、一道迁移型自测题。
5. 卡片之间必须满足前置依赖，禁止随机选题。
6. “继续”进入下一张；“复习”优先处理最近盲点；“跳过”记录依赖风险。
7. 面向知乎等发布场景时，按本文档 `外部发布/导出输出` 节执行。

### B · 速成深度教学

适合在有限时间内吃透一个边界明确的专项。

若主题无法在一个有效学习单元内讲透，先拆成 **3–7 个专项**，说明依赖关系，然后完成第一个专项。“一次完成”只指当前专项，不代表一次覆盖整门学科。

每个专项严格覆盖：

1. **原理**：解决什么问题，为什么可行。
2. **流程**：从输入到输出的关键步骤。
3. **细节**：核心参数、实现机制和边界条件。
4. **难点**：常见误区、失败原因和诊断方法。
5. **优化**：性能、质量、稳定性或学习效率提升点。

先给整体心智模型，再逐层深入。至少提供一个可操作例子。末尾给三道迁移型检验题；若叠加 D 交互，不一次展示三题，而是逐题引导。

### C · 资料地图整理

适合摸清新领域的边界、权威入口与实践顺序，也可作为 A/B 的准备阶段。

1. 按官方文档、教程、开源项目、论文、社区分类；没有决策价值的分类可省略。
2. 每条资源标注来源、难度、核心价值和何时看。
3. 核验资源是否存在、是否仍适用；优先官方资料、原始论文和主仓库。
4. 给出阶段顺序与阶段目标，区分必读、选读和查阅型资料。
5. 每阶段保留最有价值的少数资源，禁止为了显得全面而堆链接。
6. 反馈校准关注资源覆盖、顺序、难度和用户目标的适配度，不强行插入知识测验。
7. 无法联网核验时明确时效限制，不编造链接、版本或活跃度。

### D · 苏格拉底交互方式

D 不是独立学习路径，默认叠加在 A 或 B 上形成 `A+D` 或 `B+D`。叠加 D 时，节奏以 D 的逐轮互动为准，覆盖 A/B 的默认节奏。

1. 确定一个可验证的阶段目标和起点问题。
2. 每轮只问一个问题，然后停止并等待用户回答。
3. 沿“现象 → 假设 → 原理 → 边界 → 迁移”推进，但根据回答动态调整，不机械走完序列。
4. 回答正确时，只确认推理中真正成立的部分，再提高难度。
5. 回答错误时不批评、不立即公布答案；先给反例、缩小问题或指出矛盾。
6. 每轮内部更新 checkpoint，不在正常问答轮次展示状态块。
7. 用户暂停、要求总结或阶段完成时，输出知识地图、能力证据、盲点和下一阶段入口。

只有用户明确要求通过推理确定资料选择标准时才使用 `C+D`；此时问题围绕目标、可信度、难度和资源取舍，不把资源推荐伪装成唯一正确答案。

## 输出与进度契约

### 状态优先级

合并学习状态时严格使用：

1. 本轮显式输入
2. 可访问的有效 checkpoint
3. 安全默认值
4. 精准追问

显式输入只覆盖同名字段。用户说“继续”但没有有效状态时，请其粘贴 checkpoint 或确认重新开始；不得猜测上次主题、路径或进度。

### 首轮输出

直接讲解时采用最小结构：

1. `学习设定`：目标、当前水平、主路径、深度和节奏；只列必要的推断值。
2. `路线概览`：3–7 个节点，标出当前节点；C 路径改为资料阶段和阅读顺序。
3. `本次学习`：A 给第 1 张卡，B 给第 1 个专项，C 给可执行资料地图。
4. `反馈校准`：A/B 使用理解或迁移任务；C 确认资源覆盖、顺序和适配度。

D 交互首轮只给必要设定和一个起点问题，不得追加第二个问题、答案、三问列表或可见 checkpoint。

### 后续轮次输出

保持首轮的最小结构，只替换以下两项，其余设定不再重复展示：

1. `本次学习`：按连续学习指令推进——`继续`给下一单元，`复习`重处理盲点，`跳过`记录风险后推进，`加深`在当前节点扩深。
2. `反馈校准`：与首轮同路径匹配；A/B/D 用理解或迁移任务，C 校准资源决策。

D 交互的后续轮次仍只问一个问题并等待回答，不在正常问答轮次展示可见 checkpoint。

### 阶段完成输出

B 专项完成、A 阶段收尾、D 推进到迁移层时触发：

1. `能力证据`：列出本阶段已通过回答、迁移题或实践任务验证的能力。
2. `迁移校准`：B 给三道迁移型检验题；A 给一道跨卡迁移题；D 给一道迁移层问题。叠加 D 时逐题引导，不一次展示。
3. `Checkpoint`：阶段完成属于展示边界，输出完整 YAML 或精简列表。
4. `下一阶段入口`：标出依赖已满足、可推进的下一节点或专项。

### 外部发布/导出输出

面向知乎、公众号等发布场景或导出给非当前对话的消费方时：

- 隐藏 checkpoint、依赖、衍生等内部状态字段。
- 补自然导语与结尾互动问题，不使用内部术语。
- 不输出可机读的 YAML 状态块；如需跨会话复用，单独走 Checkpoint 生命周期的完整 YAML。

本文档 A 路径的发布场景规则以本节为准。

### Checkpoint 生命周期

每轮内部更新 checkpoint。仅在以下边界展示：用户暂停、阶段完成、明确要求保存，或需要跨会话/交给其他 AI 复用。

```yaml
learning_checkpoint:
  subject: "学科"
  goal: "可验证的学习目标"
  baseline: "当前水平与前置能力"
  primary_path: "A|B|C"
  interaction: "direct|D"
  depth: "入门|进阶|精通|全覆盖"
  pace: "节奏偏好，如每次一卡/每次两卡/逐轮互动"
  output_destination: "对话内|笔记|跨会话复用|交给其他AI"
  current_node: "当前位置"
  completed: ["已完成节点"]
  evidence: ["证明理解或能力的回答、迁移题或实践任务"]
  blind_spots: ["仍需校准的盲点"]
  skipped_dependencies: ["被跳过的依赖及风险"]
  next_step: "下一步"
```

对话内可展示精简列表。写入笔记、跨会话复用或交给其他 AI 时优先输出完整 YAML。

### 连续学习指令

- `继续`：从 `next_step` 开始，不重复已有能力证据覆盖的内容。
- `复习`：优先处理 `blind_spots`，然后重新验证。
- `跳过`：记录未学习节点及依赖风险，再判断能否继续。
- `加深`：保持当前节点，提升原理、边界或实践深度。
- `换交互`：保留主路径和进度，在直接讲解与 D 之间切换。
- `换路径`：保留目标、能力证据和盲点；depth 与 interaction 随新路径重算并说明，再重新组织后续路线。
- `重新规划`：根据新目标或当前水平重建路线，指出保留和失效节点。

### 质量检查

- 目标描述的是可验证能力，不只是“了解”或“掌握”。
- 当前水平影响了起点，已验证节点没有被无故重复。
- 路径顺序满足前置依赖，B 的专项范围可以在当前单元内完成。
- 校准方式匹配路径：A/B/D 检查理解，C 检查资源决策质量。
- checkpoint 的当前位置、证据、盲点和下一步互相一致。
- 外部资源和时效性事实经过核验，或已明确限制。
